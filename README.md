# ReLoader — Ультимативный менеджер запуска для Windows

![Version](https://img.shields.io/badge/version-3.1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)

**ReLoader** — это компактная, но мощная утилита на C# для автоматизации рабочего окружения. Она позволяет управлять группами приложений, следить за их состоянием и синхронизировать настройки через облако.

---

## Основные возможности

- **Умный запуск**: Автоматический запуск групп приложений при старте или по нажатию кнопки.
- **Cloud Config**: Поддержка внешних конфигураций через URL (GitHub, Gist и т.д.) или сетевые пути.
- **Global Hotkeys**: Запускайте свои программы из любого окна с помощью `Alt + R` (настраиваемо).
- **Watchdog (Сторож)**: Автоматически перезапускает упавшие или закрытые приложения.
- **Smart Launch**: Предотвращает запуск дубликатов уже открытых программ.
- **Drag-and-Drop**: Добавляйте новые программы в список запуска, просто перетащив их на окно ReLoader.
- **Stealth Mode**: Работайте полностью в фоновом режиме (только трей и горячие клавиши).
- **Кастомизация**: Настройка цветов интерфейса, центрирование окна и звуки запуска.
- **Progress Ring**: Наглядная визуализация процесса запуска приложений.
- **Планировщик задач**: Запуск, перезапуск, закрытие и перезагрузка по расписанию.
- **SHA256 проверка обновлений**: Целостность скачанного файла проверяется хешем.
- **Crash logging**: Неперехваченные ошибки пишутся в лог.

## Новое в v3.1.0.0

### Исправления багов
- **Sync-over-async deadlock** — `ConfigManager.Load()` больше не блокирует UI-поток через `.GetAwaiter().GetResult()`
- **Screen.PrimaryScreen null crash** — больше не падает на мульти-мониторных системах
- **Звук до пустой последовательности** — теперь не играет, если нечего запускать
- **SettingsForm обходил ConfigManager** — теперь использует общий кэш, нет рассинхронизации

### Безопасность
- **SHA256 проверка обновлений** — скачанный exe проверяется хешем перед заменой
- **Телеметрия off by default** — настройка `TELEMETRY=0` по умолчанию, не отправляет данные
- **Убрана запись в HKLM** — `SetRunAsAdminCompatibility` работает без прав администратора
- **Обновление без cmd.exe** — вместо инлайнового `cmd.exe /C move` используется `.bat` файл

### Производительность
- **Buffered Logger** — `StreamWriter` вместо `File.AppendAllText` на каждую строку
- **Batch saves** — `SaveContextSettings()` сохраняет файл один раз вместо пяти
- **Cached GDI объекты** — `StringFormat`, `Pen` кэшируются в `OnPaint`
- **DNS timeout** — проверка интернета с таймаутом 3 секунды

### Улучшения
- **Crash logging** — `ThreadException` и `UnhandledException` пишутся в лог
- **Watchdog cooldown** — 30 секунд между перезапусками одного процесса
- **Drag & Drop диалог** — выбор между START и AUTOSTART при перетаскивании
- **ScheduledTask валидация** — невалидные строки молча пропускаются
- **CloseSoftlyAsync timeout** — минимум 3 сек, максимум 30 сек
- **Удалена папка `ReLoader old/`**

## Установка

1. Скачайте `ReLoader.exe` из раздела [Releases](https://github.com/komoliddin/ReLoader/releases).
2. Поместите файл в любую папку (рекомендуется создать отдельную папку, так как программа создаст файл настроек и логов).
3. Запустите программу. При первом старте она автоматически создаст эталонный `ReLoaderCFG.txt`.

## Интерфейс и управление

- **Круг в центре**: Основная кнопка. Клик запускает последовательность программ.
- **Drag-and-Drop**: Перетащите `.exe` файл на окно — появится диалог выбора (START или AUTOSTART).
- **Контекстное меню (ПКМ по окну или иконке в трее)**:
  - *Настройки*: Графический интерфейс для управления всеми параметрами.
  - *Активные процессы*: Список запущенных программ из конфига.
  - *Стелс-режим*: Скрывает окно, работает через горячие клавиши и трей.
  - *Закрепить окно*: Запрещает перемещение окна мышкой.
  - *Проверить обновления*: Ручная проверка с SHA256 верификацией.

## Настройка (Интерфейс)

Выберите **"Настройки"** в контекстном меню:
- **Общие**: Автозапуск, звук, сторож, горячие клавиши, телеметрия.
- **Внешний вид**: Прозрачность, размеры, цвета.
- **Облако**: Ссылки на внешние конфигурации.
- **Приложения**: Редактирование списков `START`, `AUTOSTART`, `TASKKILL`.
- **Планировщик**: Визуальное редактирование задач.

---

## Настройка (ReLoaderCFG.txt)

| Ключ | Значение | Описание |
| :--- | :--- | :--- |
| `DELAY` | `1, 2, 3...` | Задержка в секундах между запуском приложений. |
| `HOTKEY` | `Alt+R` | Глобальная комбинация клавиш для запуска. |
| `OPACITY` | `25-100` | Прозрачность окна. |
| `LEFT/TOP` | `100 / CENTER` | Координаты окна. |
| `WATCHDOG` | `1 / 0` | Автоперезапуск закрытых программ. |
| `SMART_LAUNCH` | `1 / 0` | Не запускать дубликаты. |
| `TELEMETRY` | `1 / 0` | Отправка анонимной телеметрии (off по умолчанию). |

### Списки приложений:
- `START=путь`: Запуск только по клику.
- `AUTOSTART=путь`: Автозапуск при старте ReLoader.
- `STARTBOTH=путь`: И при старте, и при клике.
- `TASKKILL=имя.exe`: Завершение процесса перед запуском.
- `CLOSE=имя.exe`: Мягкое закрытие (Alt+F4) перед запуском.
- `CLOSE_REBOOT=имя.exe`: Закрытие + перезагрузка ПК.

## Облачная синхронизация (Cloud Config)

Добавьте в `ReLoaderCFG.txt`:
```
CONFIG=https://your-server.com/reloader_base.txt
CONFIG=C:\Network\shared_tools.txt
```

Списки из всех источников объединяются без дубликатов. Локальные списки (добавленные через Drag-and-Drop) всегда сохраняются.

---

## Удаленное управление (Blacklist)

В облачном файле:
```
REMOVE=START=C:\Games\Doom.exe
REMOVE=TASKKILL=chrome.exe
```

Программа удалит указанные значения из локальных списков пользователя.

## Планировщик задач

Формат: `SCHEDULER=ACTION|INTERVAL|TYPE|TIME|TARGET`

| Параметр | Описание |
| :--- | :--- |
| `ACTION` | `START`, `RESTART`, `REBOOT`, `TASKKILL`, `CLOSE`, `CLOSE_REBOOT` |
| `INTERVAL` | Число (для CLOSE — таймаут в сек, 0 = 30 сек по умолчанию) |
| `TYPE` | `SEC`, `MIN`, `HOUR`, `DAY`, `WEEK`, `MONTH` |
| `TIME` | `08:30` (опционально, HH:mm) |
| `TARGET` | Путь к программе или имя процесса |

Примеры:
```
SCHEDULER=START|30|MIN||C:\App\my.exe
SCHEDULER=CLOSE_REBOOT|0|SEC|06:00|iiko
SCHEDULER=TASKKILL|1|HOUR||chrome
```
