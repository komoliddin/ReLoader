# ReLoader - Журнал изменений (Change Log)

Все важные изменения в проекте фиксируются здесь.

## [3.1.0.0] - 2026-07-05
### Добавлено
- **Единая очередь выполнения**: Порядок команд в конфиге (START, TASKKILL, CLOSE) теперь жестко соблюдается.
- **Мастер задач (UI Wizard)**: В настройки добавлен "Мастер добавления" для создания сложных цепочек действий без правки текста.
- **Цвет стрелок**: Добавлен параметр `COLOR_SYNC` для независимой настройки цвета анимированных стрелок.
- **Эмуляция Alt+F4**: Метод `CLOSE` теперь пытается закрыть программу через `CloseMainWindow` перед убийством процесса.
- **Поддержка внешних конфигураций**: Новый параметр `CONFIG=` позволяет загружать настройки из URL, сетевых путей или локальных файлов.
- **Центрирование окна**: Параметры `LEFT=CENTER` и `TOP=CENTER` для автоматического позиционирования окна по центру экрана.
- **Разделители в меню**: Улучшена визуальная структура контекстного меню.
- **Поддержка нескольких CONFIG=**: Теперь можно указывать несколько строк `CONFIG=` для слияния настроек из разных источников.
- **Умное слияние (Smart Merge)**: Ваши локальные списки приложений не затираются, а объединяются с облачными.
- **Удаленное управление (Blacklist)**: Поддержка команды `REMOVE` в облачных конфигах для административной очистки локальных списков.
- **Планировщик задач (Scheduler)**: Реализована возможность запускать, перезапускать приложения или перезагружать ПК по расписанию.
- **Новые действия планировщика**: Добавлены `TASKKILL` и `CLOSE` (мягкое закрытие с таймаутом).
- **Поддержка SEC**: Новый тип интервала для планировщика (секунды).
- **Графический интерфейс настроек (Settings UI)**: Реализовано полноценное окно настроек с вкладками.
- **Универсальные исключения**: Команда `REMOVE_...` заменена на единый формат `REMOVE=КЛЮЧ=ЗНАЧЕНИЕ`.
- **Захват клавиш**: В настройках реализован автоматический перехват горячих клавиш.
- **Drag & Drop диалог** — выбор между START и AUTOSTART при перетаскивании `.exe`.
- **ScheduledTask валидация** — невалидные строки молча пропускаются.
- **ConfigManager.UpdateSettingsBatch** — пакетное обновление настроек.
- **Crash logging** — неперехваченные ошибки пишутся в лог.

### Улучшено
- **Интерфейс**: Вкладка "Списки и задачи" переработана в удобную таблицу с кнопками управления порядком действий (▲, ▼, ✖).
- **Логирование**: Детальное логирование процессов закрытия, поиска и срабатывания планировщика в `ReLoaderLOG.log`.
- **Стабильность**: Устранена проблема ложного срабатывания планировщика.
- **Высококачественный рендеринг окна**: Заменена старая логика округления (`Region`) на `TransparencyKey` и антиалиасинг (`AntiAlias`).
- **Визуальный стиль**: Текст теперь имеет черную обводку для лучшей видимости. Значок синхронизации (стрелки) виден всегда.
- **Интерфейс**: Вкладки настроек объединены для упрощения. Добавлены подсказки по формату планировщика.

### Исправлено
- Баги компиляции в дизайнере форм.
- Логика поиска процессов (корректное нахождение по имени с поддержкой *).
- Скрытие консольных окон при выполнении `taskkill` и запуске программ.
- Исправлено отображение галочки для пункта «Создать ярлык на рабочем столе».
- Оптимизирован порядок пунктов в контекстном меню для более удобного доступа.
- Переработан механизм создания конфигурации по умолчанию (теперь со всеми подсказками).
- Исправлено ложное срабатывание планировщика при каждом клике или обновлении настроек (состояние LastRun теперь сохраняется).
- Исправлены ошибки рендеринга и «розовые рамки» на краях окна.
- **Sync-over-async deadlock** в `ConfigManager.Load()` — больше не блокирует UI-поток.
- **Screen.PrimaryScreen null crash** — больше не падает на мульти-мониторных системах.
- **Звук до пустой последовательности** — теперь не играет, если нечего запускать.
- **SettingsForm обходил ConfigManager** — теперь использует общий кэш, нет рассинхронизации.
- **CloseSoftlyAsync timeout** — минимум 3 сек, максимум 30 сек (было 10 по умолчанию при 0).
- **`.exe` stripping** — используется `Path.GetFileNameWithoutExtension()` вместо `.Replace`.

### Безопасность
- **SHA256 проверка обновлений** — скачанный exe проверяется хешем перед заменой.
- **Телеметрия off by default** — настройка `TELEMETRY=0` по умолчанию.
- **Убрана запись в HKLM** — `SetRunAsAdminCompatibility` работает без прав администратора.
- **Обновление без cmd.exe** — вместо инлайнового `cmd.exe /C move` используется `.bat` файл.

### Производительность
- **Buffered Logger** — `StreamWriter` вместо `File.AppendAllText` на каждую строку.
- **Batch saves** — `SaveContextSettings()` сохраняет файл один раз вместо пяти.
- **Cached GDI объекты** — `StringFormat`, `Pen` кэшируются в `OnPaint`.
- **DNS timeout** — проверка интернета с таймаутом 3 секунды.
- **Crash logging** — `ThreadException` и `UnhandledException` пишутся в лог.
- **Watchdog cooldown** — 30 секунд между перезапусками одного процесса.

### Изменено
- Из контекстного меню удалены пункты "Редактировать список приложений" и "Полная очистка".
- Обновлена документация (`README.md`): добавлена инструкция по мульти-конфигам и удаленному управлению.

### Удалено
- Папка `ReLoader old/` (устаревший код).
- Мёртвые поля: `originalBackground`, `_animationStep`, `_currentOpacity`, `TaskToKill`.
- Неиспользуемый `using System.Threading` в Logger.cs.

## [2.6.0.0] - 2026-02-01
### 🚀 Глобальное обновление
Это крупнейшее обновление в истории проекта, включающее полную переработку архитектуры и множество новых функций.

### Добавлено
- **Модульная система**: Код разделен на независимые блоки (`AppLauncher`, `ConfigManager`, `Logger`) для повышения надежности.
- **Горячие клавиши**: Добавлена поддержка глобальных сочетаний клавиш (по умолчанию `Alt+R`).
- **Стелс-режим**: Возможность работы без окна программы (только в трее).
- **Индикатор прогресса**: Добавлено графическое кольцо (Progress Ring), отображающее ход запуска приложений.
- **Drag-and-Drop**: Добавление программ в список перетаскиванием файлов на форму.
- **Watchdog**: Режим автоматического контроля и перезапуска процессов.
- **Smart Launch**: Защита от запуска нескольких копий одной и той же программы.
- **Динамическое меню**: Теперь в трее отображается список реально запущенных приложений.
- **Безопасность**: Автоматическое создание бэкапа настроек (`ReLoaderCFG.txt.bak`).
- **Переезд на GitHub**: Обновления теперь скачиваются напрямую с GitHub.

### Изменено
- Весь процесс запуска теперь полностью асинхронный (UI не зависает).
- Расширена система логирования всех действий пользователя.
- Улучшена совместимость с Windows 10/11 (автоматическая настройка прав администратора).

### Исправлено
- Исправлены критические ошибки при работе с реестром.
- Исправлена логика удаления и создания ярлыков.
